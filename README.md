# VplusCheckerGV

## Installation
1. [Download](../../releases/latest) source code for latest release
```
▼ Assets
    Source code (zip)
    Source code (tar.gz)
```
2. Open downloaded archive (zip or tar.gz)
3. Copy folder `VplusCheckerGV` to `WoW\Interface\AddOns`
```
VplusCheckerGV-<version>.zip
└── VplusCheckerGV-<version>\
    ├── VplusCheckerGV\        <-- this folder
    ├── README
    └── LICENSE
```
