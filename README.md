# VplusCheckerGV

## Installation
1. [Download](../../releases/latest) source code for latest release
1. Open downloaded archive (zip or tar.gz)
1. Copy folder `VplusCheckerGV` to `WoW\Interface\AddOns`
```
VplusCheckerGV-<version>.zip
└── VplusCheckerGV-<version>\
    ├── VplusCheckerGV\        <-- this
    ├── README
    └── LICENSE
```
